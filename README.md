# ItemCleaner

Плагин для Paper/Spigot 1.20, автоматически очищающий брошенные предметы (Item-сущности) во всех мирах сервера **VortexiaPolit** раз в 2 часа, с предупреждениями в чат за 2 часа, 1 час, 30/15/10/5/3/2/1 минут до очистки.

Опыт, торговые сущности и содержимое сундуков не затрагиваются — удаляются только предметы, лежащие на земле.

## Команды

| Команда | Описание |
|---|---|
| `/itemclean` | Показать время до следующей очистки |
| `/itemclean run` | Запустить очистку немедленно и сбросить таймер |

Право: `itemclean.admin` (по умолчанию только ОП).

## Сборка

```
compile.bat
```

## Совместимость

- Minecraft **1.20.1**
- Ядро сервера: **Mohist 1.20.1** (плагин используется на сервере VortexiaPolit)
- Написан на Bukkit/Spigot API, поэтому может работать и на Paper/Spigot 1.20.x
